# Work Time Tracker 2.1 / Учёт рабочего времени

## Запуск (Windows)

1. Распакуйте архив в отдельную папку.
2. **Скопируйте `worktime.sqlite3` из старой папки в новую**, если хотите сохранить сотрудников и записи. Перед копированием остановите старый сервер (`Ctrl+C`). Не заменяйте существующую базу пустой.
3. Запустите `start.bat` или выполните `py app.py`.
4. Откройте `http://localhost:8000`.

Требуется Python 3.10+; сторонние пакеты Python не нужны. Интернет нужен только для перевода описаний задач. Сервер слушает `127.0.0.1:8000`, доступен только с этого компьютера.

## Языки и перевод

В верхнем правом углу переключайте Русский / English. Вводите имя или описание задачи **один раз** на текущем языке. Имена транслитерируются локально (написание может быть неточным), а описания задач переводятся через бесплатный публичный API MyMemory. Результат хранится в SQLite и не переводится повторно при переключении языка. При недоступности API задача не запускается, выводится ошибка; попробуйте позже. Сервис MyMemory не гарантирует постоянную бесплатную доступность и может ограничивать количество запросов. Не отправляйте конфиденциальные данные в описаниях задач: текст уходит стороннему сервису. Тексты старых записей без перевода отображаются на исходном языке, пока не будут исправлены через «Редактировать переводы».

Редактирование открывает два поля для ручного исправления русской и английской версии. При смене языка интерфейс и сохранённые переводы меняются сразу. Язык сохраняется в браузере.

## Возможности

Добавление, редактирование и удаление сотрудников; запуск и остановка таймера; запрет двух активных таймеров для одного сотрудника; живой счётчик; отчёт за даты (границы дня UTC+5); редактирование текстов записей, удаление записей; экспорт CSV, открываемый Excel. Удаление сотрудника удаляет и его историю. SQLite сохраняет данные после перезапуска. Нет авторизации.

## Тесты

`py -m unittest discover -s tests -p "test_v21.py" -v`

Проверяются: русские и английские имена, сохранение перевода после повторной инициализации БД, повторный запуск таймера, остановка, пустой отчёт, ошибка сервиса перевода без создания записи, миграция старых данных. Внешний API в тестах подменён заглушкой: реальная доступность MyMemory и браузерный UI автоматическими тестами не проверяются.

## ИИ-инструменты и исправления

Использовалась модель OpenAI GPT-6 (ChatGPT) для разработки, анализа и генерации тестов; локальный Python `unittest` для исполнения проверок. Примеры запросов: «Добавь русский и английский языки с одним полем ввода», «Сохрани совместимость SQLite с предыдущей версией», «Проверь повторный запуск таймера и пустой отчёт», «Добавь бесплатный перевод и обрабатывай ошибки сети». В процессе разработки исправлены: лишний вызов API перевода для имён (заменён локальной транслитерацией), ошибочная обработка экспорта CSV через POST вместо GET, несовместимый с одним полем старый UI. Известные ограничения: машинный перевод и транслитерация имён могут требовать ручной правки; старые записи не переводятся автоматически; MyMemory может быть недоступен или ограничивать запросы.

### Windows launcher (updated)

Run `python launch.py` from PowerShell. It starts the server and opens the browser after the server responds. Alternatively use `start.bat`; if Windows blocks downloaded `.bat` files, use the Python command rather than disabling Windows security features. The original `python app.py` remains supported (without automatic browser opening).

If an action fails, inspect the PowerShell output and browser DevTools Network response. Translation depends on the external MyMemory service and may fail independently of the launcher.

## Версия 2.2 — модальное подтверждение удаления

Стандартные `window.confirm()` заменены на адаптивное модальное окно по центру экрана с затемнением фона, русским и английским текстом, названием удаляемого сотрудника или задачи и предупреждением о необратимости удаления. Поддерживаются отмена, Escape, закрытие по крестику или фону, фокус внутри окна и восстановление фокуса после закрытия. Отмена не отправляет запрос удаления. **Обновление:** остановите старую версию, распакуйте архив в новую папку, скопируйте туда ваш `worktime.sqlite3`, затем выполните `python launch.py`. При необходимости обновите страницу в браузере с `Ctrl+F5`. Старую папку не удаляйте до проверки данных.

**Проверки версии 2.2:** пять автоматических тестов Python (миграция, транслитерация, сохранение перевода, повторный таймер, пустой отчёт и отказ переводчика в составе тестовых сценариев) успешно выполнены; синтаксис JS проверен командой `node --check`. Дополнительно проверено отсутствие вызовов нативного `confirm()` в интерфейсе. Ручное браузерное тестирование модального окна требуется выполнить на вашем компьютере.

**ИИ-инструменты:** ChatGPT (OpenAI GPT-6) для проектирования диалога и изменений HTML/CSS/JS. Примеры запросов: «Замени системный confirm на окно по центру», «Предупреждай об удалении всей истории сотрудника», «Добавь поддержку Escape и двух языков». Исправлены зависимость оформления от системного диалога браузера и отсутствие контекста удаляемой записи в предупреждении.

## Work Time Tracker 3.0 — Dark Professional

Обновление дизайна: тёмная тема по умолчанию, переключение тёмной/светлой темы (настройка сохраняется в `localStorage`), адаптивная боковая навигация, четыре KPI-карточки, диаграмма рабочего времени по дням и горизонтальное сравнение сотрудников. Подписи диаграмм переключаются между русским и английским. Диаграммы строятся из записей за период, выбранный в отчёте, и обновляются при нажатии «Показать отчёт». Активные таймеры показываются отдельным показателем, а часы отражают данные отчёта. Для длительных периодов столбцы группируют несколько дней.

**Совместимость:** серверный `app.py` и схема SQLite сохранены от версии 2.2. База `worktime.sqlite3` не включена в архив. Перед переносом сделайте резервную копию старой базы и скопируйте её в папку новой версии. Запуск: `python launch.py` или `python app.py`.

**Проверки:** `python -m unittest discover -s tests -v`; синтаксис встроенного JavaScript можно проверить через `node --check` после извлечения блока `<script>` из `static/index.html`. Устаревший тест узбекского языка заменён проверкой текущей русско-английской модели. Ручное тестирование в браузере на Windows рекомендуется после установки.

**ИИ-инструменты и модель:** разработка и ревизия кода выполнены с помощью ChatGPT (GPT-6); для запуска проверок использовались Python `unittest` и Node.js. Примеры запросов: «Добавь тёмную тему с переключением и сохранением выбора»; «Построй график времени по дням из существующего отчёта»; «Сохрани совместимость с SQLite и двухъязычным интерфейсом»; «Проверь сценарий пустого отчёта и повторного запуска таймера». Исправления: удалено устаревшее ожидание узбекского языка в тесте, проверена корректность обновления графиков после смены периода, добавлено состояние пустых диаграмм.

**ИИ-инструменты:** ChatGPT (GPT-6) для проектирования SPA-навигации, оформления и тестов; Python unittest и Node.js для локальной проверки. Примеры запросов: «Замени якорную навигацию на SPA-панели», «Сделай Soft Slate Blue без чёрного фона», «Сохрани API и совместимость SQLite», «Проверь отсутствие открытия новых вкладок». ## Обновление 3.2: синхронизация активных задач

В разделе «Отчёты» активные задачи отображаются со статусом «Работает / Working», а их длительность и итог по сотруднику обновляются каждую секунду. Панель «Обзор» и графики пересчитываются на основе тех же записей. Фоновая синхронизация с SQLite каждые 15 секунд добавляет недавно запущенные задачи в отчёт. Расчёт за период ограничивается датами в часовом поясе UTC+05:00; исторические завершённые записи не изменяются. При переключении вкладок браузера таймер пересчитывается по абсолютному времени, а не накапливает тики.

**Обновление:** распакуйте архив в новую папку, скопируйте `worktime.sqlite3` из предыдущей версии, запустите `python launch.py`, обновите браузер `Ctrl+F5`. Резервную копию SQLite сохраните отдельно.

## Work Time Tracker 3.3 — Coral & Ocean

- Theme: `#FFF2DB`, `#FFAB5B`, `#00879E`, `#003092`. Light and dark themes remain available.
- Export CSV uses UTF-8 BOM and semicolon delimiter (`;`) for better WPS Office / regional Excel compatibility.
